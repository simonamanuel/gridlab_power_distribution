# Demo outline (2–3 minutes)

1. Show the network layout and equipment details: 13.8 kV source, 500 kVA transformer, 600 V bus, three feeders.
2. Increase Manufacturing demand and show the main bus voltage and transformer loading change.
3. Demonstrate opening FDR-01 and show the unserved demand while the two other feeders remain supplied.
4. Reset the switch and run the three-phase fault study for FDR-01. Explain that the pickup decision is illustrative, not a coordinated relay model.
5. Open the Engineering Notes or Project Assistant panel, and point out which measurements come from pandapower.
6. Show the test suite and reproducible validation report.

This is a fictional training model, not an operating utility system.
